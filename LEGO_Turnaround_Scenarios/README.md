# LEGO Turnaround — three scenario concepts for review

Three ways to stage the case in `LEGO_Turnaround_Simulation.md` (8 capacity units, four proposals costing 4 / 2 / 3 / 5,
a board pitch, the 2004–2005 archive). Each concept has an Arabic and an English PDF. They are scenarios for review:
no game is built from them until one is chosen.

| Concept | Idea | Arabic | English |
| --- | --- | --- | --- |
| A — «طاولة الثمانية» | A product worktable: eight wooden blocks in a rack, pressed by hand onto the proposals' bases | [PDF](Concept-A_Table_AR.pdf) | [PDF](Concept-A_Table_EN.pdf) |
| B — «أرضية المصنع» | Capacity is people: eight named staff on a factory floor, assigned from a floor-plan board on the mezzanine | [PDF](Concept-B_Floor_AR.pdf) | [PDF](Concept-B_Floor_EN.pdf) |
| C — «الشحنة» | Capacity is space: an eight-slot pallet lane, each proposal a crate whose length is its cost | [PDF](Concept-C_Shipment_AR.pdf) | [PDF](Concept-C_Shipment_EN.pdf) |

Each document covers the idea, the set with a top-down sketch, the cast, the four scenes with every hands-on action and
its button alternative, the full dialogue (Arabic with English), a map from every spec requirement to where it is met,
the historical facts with their report pages, and open questions to decide.
